# Topological-Quantum-Computing-with-Annoys

This repository contains numerical tools and examples for topological quantum computing with non-Abelian anyons, particularly with Fibonacci and Ising anyons. The examples are associated with the paper

**Kritanjan Polley and Mark E. Tuckerman,  
"Scalable Simulation of Quantum Dynamics on Topological Quantum Hardware"**  
[arXiv:2609.19484](https://arxiv.org/abs/2609.19484) ·
[PDF](https://arxiv.org/pdf/2609.19484)

The central goal is to represent real time quantum propagators as sequences of anyonic braids and use these braid operations to construct approximate propagators. The implementation combines the algebra of anyonic fusion and braiding with the Solovay–Kitaev algorithm for compiling target unitary transformations into sequences of elementary braid generators.
